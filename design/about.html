02 — Agents

Agents don't need an integration. They need a key.

Most software keeps programs out until someone signs off: a developer account, an API key, a review, a scope. Nostr doesn't work that way. Every app reads and writes the same signed events over the same open protocol, so an agent with a key can do what any other client does. It can read a form's responses, put a meeting on a calendar or edit a shared document.

@formstr/mcp packages that for MCP hosts such as Claude, Cursor and Goose: more than seventy tools across the suite, set up with one command.

Key custody

OS keychain, NIP-49 encrypted, or a remote signer. Keys never enter the conversation.

Guardrails

Outward and destructive actions need --allow-writes and confirm: true.

Any model

Works with any MCP host, including local models through Goose and Ollama.

Install

npx -y @formstr/mcp
Open source on npm.

03 — Security

Security you can check, not just trust.

Encryption happens in your browser before anything is sent. Relays store ciphertext and signatures. They can't read your content, and neither can we. The code that does this is open for your security team to review.

Identity
A key pair, not an account. Sign in with a browser extension, a remote signer (NIP-46) or a local key.
Encryption
NIP-44, performed on your device. Shared items are delivered with NIP-59 gift wraps.
Data location
Relays you choose. Run your own to keep data inside your network.
Files
Blossom servers you choose, public or self-hosted.
Audit trail
Every change is a signed event. Each one says which key, person or agent, made it.
Tracking
No analytics and no advertising. Privacy policy
